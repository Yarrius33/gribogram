# Project memory

Notes loaded into dsc sessions for this project.

## Notes
- Проект: Telegram Web A (форк)

## Цели проекта
Создать веб-клиент Telegram с расширенными функциями для личного использования:
- Копирование в защищённых чатах
- Бесконечный просмотр одноразовых фото
- Отложенная отправка сообщений
- Мультиаккаунтность (до 10 аккаунтов)
- Кастомизация интерфейса

## Технологический стек
- React + TypeScript
- MTProto API
- Webpack

## Требования к коду
- Сохранять совместимость с оригинальным Telegram Web A
- Изменения должны быть модульными
- Добавлять toggle-опции в настройках
